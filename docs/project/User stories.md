# User stories


## Fase 2 - KISS

Als KCC medewerker:
- inloggen (als medewerker)
- contactverzoek vastleggen voor inwoner
- contactverzoek vastleggen voor ondernemen
- contactverzoek terug vinden
- Op zaken kunnen zoeken
- Afdelingen en groepen zoeken en inzien

Als KCC supervisor wil ik:
- inloggen (als supervisor)
- nieuwsberichten publiceren
- werinstructies publiceren
- Skills kunnen beheren
- Kanalen kunnen beheren (kanalen is de KISS term voor categorien?)
- Links beheren
- Rapportages?

## Fase 3 - ITA
Als KCC medewerker wil ik:
- Terugbelverzoek maken voor een medewerker
- Terugbelverzoek maken voor een afdeling
- Terugbelverzoek maken voor een team (groep)

Als medewerker wil ik:
- Inloggen bij ITA
- Notificaties van een terugbelverzoek ontvangen
- Terugbelverzoek afhandelen in ITA

## Fase 4 - Kennisbank en website
Als KCC medewerker wil ik:
- Eenvoudig door de kennisbank zoeken
- Eenvoudig door de website zoeken
